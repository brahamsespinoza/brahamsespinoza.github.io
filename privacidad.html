Alertas personales

Política de privacidad

Alertas personales es una aplicación de uso personal. Esta página explica qué datos usa y para qué.

Última actualización: 27 de octubre de 2026

En resumen: la aplicación la uso solo yo. Usa la API de Gmail únicamente para enviar notificaciones automáticas a mi propio correo. No lee mi bandeja de entrada y no almacena ni comparte datos con terceros.

Qué es la aplicación

Alertas personales es un programa que se ejecuta en mi computadora personal y me envía notificaciones automáticas por correo. No es un servicio abierto al público ni tiene otros usuarios.

Uso de la API de Gmail

  • Solo solicita el permiso gmail.send (enviar correo en mi nombre).
  • Se usa únicamente para enviar notificaciones desde mi cuenta de Gmail a mi propio correo.
  • No lee, busca, modifica ni elimina correos, y no accede a contactos, calendario ni a ningún otro dato de la cuenta de Google.

Datos que se guardan

  • Permiso de acceso (token de Google): se guarda solo en mi computadora, en una carpeta privada, y sirve únicamente para enviar los correos.
  • Registro de notificaciones: un registro local de las notificaciones ya enviadas, para no repetir avisos.
  • No se recopilan datos de otras personas ni se usan cookies, analíticas o publicidad.

Terceros

Los datos no se venden, no se comparten y no se transfieren a terceros, ni se usan para publicidad ni para entrenar modelos de inteligencia artificial. El uso de la información recibida de las API de Google cumple la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de uso limitado.

Revocar el acceso

El permiso puede revocarse en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, la aplicación deja de poder enviar correos y el token guardado deja de funcionar.
